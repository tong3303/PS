# Backtracking Study Strategy

백트래킹 알고리즘에 대해 공부를 하다가 코드를 따라 치는 느낌이 들고, 단순히 타이핑 연습을 하는 거 같아서 상태 공간 탐색부터 천천히 시작해보려고 합니다.

## 1. 사고의 기본: State Space Search
주어진 상태에서 할 수 있는 모든 행동을 트리 형태로 탐색하며 목표 노드를 찾는 과정입니다. 이를 위해 문제를 풀기 전 다음 세 가지 요소를 명확히 정의해야됩니다.

* **State (상태):** 현재 내가 어디에 있는가?
* **Transition (전이):** 한 상태에서 다른 상태로 어떻게 이동하는가?
* **Goal State (목표 상태):** 도달하고자 하는 종료 조건은 무엇인가?

---

## 2. 문제 해결 알고리즘 규율 (Rule-Set)

문제를 풀 때 제가 따를 규율입니다. 문제를 풀면서 해당 규율은 수정해나갈 계획입니다.

1.  **상태 정의:** 문제를 읽고 "현재 상태는 [___]이다"라고 한 문장으로 정의하기
2.  **전이 정의:** "이 상태에서 선택할 수 있는 행동은 [___]이다"라고 정의하기
3.  **목표 및 종료 조건 정의:** 기저 상태, 종료 상태 정의내리기
4.  **Pseudo-code 작성:** sudo code 작성해보기
5.  **파라미터 설정:** 작성한 sudo 코드를 상상 속으로 돌려보며, 파라미터 선정하기
6.  **디버깅 및 회고:** 막히는 지점이 생기면 즉시 멈추고, 원인을 한 문장으로 명시하기
7.  **답안 대조 및 복기:** 답을 확인한 후 코드를 닫고, 백지에서 다시 구현해보기
8.  **교차 검증:** 완성된 코드가 초기 정의한 1~3번(상태/전이/목표)의 논리와 일치하는지 확인하고, 주석을 추가
